# 🏢 AI_Criterio — Virtual Pixel Art Agency Headquarters

Plataforma visual interactiva estilo **Pixel Art** que alberga los **296 agentes especializados** del repositorio [agency-agents](https://github.com/msitarzewski/agency-agents.git), trabajando activamente en los distintos departamentos de tu negocio **AI_Criterio**.

---

## 🚀 Inicio Rápido (1 Clic)

### Opción 1: En Windows (Doble clic)
Haz doble clic sobre el archivo:
```bat
start_agency.bat
```

### Opción 2: Desde la Terminal
```bash
cd "C:\Users\onaga\.antigravity-cuenta2\.gemini\antigravity\scratch\ai-criterio-agency"
python server.py
```
Abre tu navegador en: **`http://localhost:8080`**

## ✨ Características Principales

1. **Simulación de Oficina en Pixel Art 2D**:
   - Canvas interactivo con renderizado pixelado nítido (`crisp-edges`).
   - Ciclo de animación: agentes tecleando en sus escritorios, caminando al café o enfriador de agua, globos de pensamiento dinámicos.
   - Controles de cámara: Pan (arrastrar con ratón o teclas WASD), Zoom (rueda o botones HUD `+` / `-`), y Minimap interactivo.

2. **Terminal de Consulta y Asesoría para AI_Criterio**:
   - Haz clic en cualquier agente para abrir su expediente.
   - **Modo Consulta Inmediata**: Botones tácticos preconfigurados:
     - *"¿Cuál es tu prioridad #1 para AI_Criterio hoy?"*
     - *"Diseña un plan de acción de 14 días"*
     - *"¿Qué métricas y KPIs debemos medir?"*
     - *"Audita riesgos y cuellos de botella"*
   - **Motor Dual de Inteligencia**:
     - *Modo Local Inteligente (Offline)*: Genera diagnósticos y respuestas estructuradas adaptadas al contexto y pilares de AI_Criterio.
     - *Modo Conectado (Gemini / OpenAI)*: Introduce tu API Key en Ajustes para razonamiento LLM en vivo.

3. **Sala de Crisis (War Room) / Sesión Multidisciplinar**:
   - Convoca una reunión de choque para resolver cualquier desafío de AI_Criterio (ej. *"Lanzar plataforma de auditoría de agentes"*).
   - El sistema convoca automáticamente a los agentes idóneos de diferentes departamentos.
   - Debate simulado paso a paso con generación de un **Plan Estratégico Maestro** exportable.

4. **AI_Criterio Business Hub**:
   - Edita en tiempo real el nombre, misión, eslogan, target corporativo, objetivo prioritario y proyectos activos de tu negocio.
   - Todos los agentes toman en cuenta este contexto en sus análisis y recomendaciones.

5. **Audio Retro Sintetizado & Modo CRT**:
   - Efectos sonoros 8-bit sintetizados en tiempo real mediante Web Audio API (sin descargas de audio externas).
   - Efecto visual de monitor CRT con scanlines retro activable en 1 clic.
